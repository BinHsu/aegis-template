## What it is defending against

On 2026-08-24 one request was read as "every repo's issues". Five repos were edited; four of those
were out of bounds. The loss was not that the edits were bad. It was that the next person inherited
two half-finished things and no record of where the middle was.

**It stops "while you're here".** Doing A, noticing B also needs a fix, and going to fix B, leaves
A unfinished and B half-done. Writing B in the report is finishing the turn. Starting a second
working tree is crossing.

See / verdict / edit are three scopes. Collapsing them is how five repos get touched at once.
Account-wide crawl (`handoff`) is See. A one-line verdict on a cloned repo is not an edit. Edit is
the current branch of the current repo unless explicitly asked to cross.

## What this case must not become

A restatement of the ENGINEERING.md table. If the global wording changes, this pointer still
works; a copied table does not.
